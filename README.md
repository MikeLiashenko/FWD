# ЗДТ — Зацікавлення Днів Тижня

Сімейний щоденник за договором [Contract_v2.pdf](Contract_v2.pdf): ШІ щодня придумує завдання, син виконує їх і отримує бліски, батьки перевіряють, бліски перетворюються на гривні.

## Запуск

Потрібен Node.js 22.13 або новіший.

**У Windows:** двічі клікніть `ZDT.cmd`. Відкриється вікно сервера — не закривайте його, поки користуєтесь додатком. Щоб зупинити сервер, закрийте вікно.

Або з командного рядка:

```bash
npm install
npm start
```

Відкрийте http://localhost:3000. Під час першого запуску вкажіть ім'я та дату народження сина, PIN для сина і спільний PIN для батьків.

З телефону в тій самій Wi-Fi відкривайте адресу, яку сервер друкує при старті і яка починається на `192.168.` (на кшталт `http://192.168.1.98:3000`). Якщо Windows спитає про брандмауер, дозвольте доступ для приватних мереж. На телефоні додаток можна «Додати на головний екран».

## Постійне посилання звідусіль (Cloudflare + GitHub Pages)

1. Сервер запускає безкоштовний Cloudflare Tunnel (`cloudflared`) і отримує адресу `https://….trycloudflare.com`. Вона змінюється при кожному запуску.
2. Нову адресу сервер записує у Firebase, у `/zdt_link` — це єдине місце бази, яке правила дозволяють читати всім.
3. Сторінка `docs/index.html` на GitHub Pages читає адресу й перекидає туди, якщо ноутбук відповідає.

Налаштування: встановіть `cloudflared` (`winget install Cloudflare.cloudflared`), у `.env` додайте `ZDT_TUNNEL=on` і `ZDT_PUBLIC_URL=` з адресою сторінки на GitHub Pages, а в правилах Realtime Database — `"zdt_link": { ".read": true }`. GitHub Pages: гілка `main`, папка `/docs`.

Оскільки додаток доступний з інтернету: PIN — від 6 цифр; після 5 невдалих спроб з інтернету акаунт блокується на 15 хвилин, після 10 з однієї адреси — адреса на годину; першу настройку можна зробити лише на самому ноутбуці.

## Доступ звідусіль (Tailscale)

Щоб відкривати додаток не лише вдома, а з будь-якого місця:

1. Встановіть Tailscale (https://tailscale.com/download) на комп'ютер і на телефони та увійдіть усюди в один акаунт.
2. Запустіть сервер — у вікні з'явиться адреса «звідусіль через Tailscale», на кшталт `http://назва-комп'ютера:3000`.
3. На телефоні ввімкніть Tailscale і відкрийте цю адресу.

Додаток бачать лише пристрої вашої сім'ї в Tailscale, в інтернеті він не опублікований. Комп'ютер має бути ввімкнений і не спати.

Автозапуск: ярлик на `ZDT.cmd` у папці автозавантаження Windows (`Win+R` → `shell:startup`). Щоб вимкнути автозапуск, видаліть ярлик звідти.

## Хмарна копія бази (Firebase)

Додаток працює з локальною базою `data/zdt.db`, а кожна зміна (бліски, завдання, оцінки, фото) за кілька секунд копіюється у Firebase Realtime Database, у розділ `/zdt`. Якщо запустити додаток на комп'ютері з порожньою базою, він сам відновить усі дані з хмари.

1. У Firebase Console: Project settings → Service accounts → **Generate new private key**. Збережіть файл як `firebase-key.json` у папці додатка (у git він не потрапляє).
2. У `.env` додайте `FIREBASE_DATABASE_URL=` з адресою вашої Realtime Database.
3. Перезапустіть сервер. Стан синхронізації видно в «Ще → Налаштування → Хмара Firebase».

Додаток пише в базу ключем адміністратора, тож правила безпеки йому не заважають. **Не відкривайте розділ `/zdt` для читання** у правилах Realtime Database: там дані дитини.

## ШІ-завдання

Без ключа завдання беруться з вбудованого банку (`src/taskBank.js`). Щоб їх придумував ШІ, створіть файл `.env` за зразком `.env.example` і вставте ключ:

- **Google Gemini** — `GEMINI_API_KEY` з https://aistudio.google.com/apikey. Модель за замовчуванням — `gemini-flash-latest`; доступні моделі показує `node --env-file=.env scripts/gemini-models.mjs`.
- **Claude** — `ANTHROPIC_API_KEY` з https://console.anthropic.com (використовується, якщо ключа Gemini немає).

Ключ потрібен з акаунта дорослого. Якщо ШІ не відповідає, завдання береться з банку.

## Де що лежить

- `src/server.js` — API
- `src/tasks.js` — життя завдання: створення, перегенерація, здача, перевірка, дедлайни
- `src/ai.js` — генерація завдань через Claude API
- `src/db.js` — база SQLite (`data/zdt.db`) і налаштування
- `public/` — інтерфейс (без збирання, звичайний JS)
